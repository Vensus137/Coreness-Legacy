# Гайд по логированию

Логи пишутся **только в файл** (один файл, без консоли). Логгер передаётся во все плагины; каждый плагин получает именованный логгер через `get_logger(plugin_name)`.

---

## Уровни

### ERROR — ошибки

Используем при сбоях: процесс нарушен, нужна внимание.

**Примеры:**
- Ошибка загрузки конфига
- Исключение при выполнении действия
- Критическая ошибка при инициализации

```python
self.logger.error(f"Ошибка загрузки файла {path}: {e}")
self.logger.exception("Ошибка при обработке запроса")  # с трейсбеком
```

### WARNING — предупреждения

Что-то пошло не так, но работа продолжается.

**Примеры:**
- Файл не найден, используется значение по умолчанию
- Плагин отключён в конфиге
- Отсутствует необязательный параметр

```python
self.logger.warning(f"Конфиг не найден: {path}, используем дефолты")
```

### INFO — важные события

Кратко и по делу: только то, что реально нужно для понимания работы приложения. **Не перегружаем** лишними сообщениями.

**Примеры:**
- Успешная инициализация плагина
- Загрузка настроек завершена
- Запуск/остановка фоновых задач

```python
self.logger.info("Global settings loaded")
self.logger.info(f"Started async background task for {name}")
```

### DEBUG — отладка

В основном для отладки во время разработки. В продакшн-коде может встречаться в исключительных случаях; без необходимости в продакшн debug не добавляем.

---

## Правила

1. **Лаконично** — без лишних деталей и «внутренностей» других функций.
2. **Без эмодзи в логах** — при необходимости можно использовать символы ✓ (успех/ок) и ✗ (ошибка/плохо) прямо в тексте сообщения.
3. **Контекст в сообщении** — при необходимости указываем плагин/действие в тексте; в файле уже есть имя логгера (`app.plugin_name`).
4. **INFO по необходимости** — не логируем каждый шаг; ошибки и предупреждения — всегда.

---

## Примеры

В комментариях: ✓ — хорошо, ✗ — плохо. В самих логах символы ✓/✗ можно использовать вместо эмодзи, когда это уместно (не обязательно в каждом сообщении).

```python
# Ошибка с контекстом
self.logger.error(f"Ошибка синхронизации: {e}")

# Исключение с трейсбеком
self.logger.exception("Ошибка при отправке сообщения")

# Предупреждение
self.logger.warning(f"Плагин {plugin_name} отключён в конфиге")

# Краткий инфо
self.logger.info("MainWindow initialized")

# При желании — ✓/✗ в тексте лога (замена эмодзи)
self.logger.info("✓ Настройки загружены")
self.logger.warning(f"✗ Плагин {name} недоступен, пропускаем")

# ✗ Лишний инфо
self.logger.info("Открываю файл, читаю строку 1, строку 2...")
```
